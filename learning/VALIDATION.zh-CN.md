## 3. 每次运行填写的记录

| 字段 | 内容 |
| --- | --- |
| 日期、运行 ID | 使用独立实验目录 |
| 源码与差异 | HEAD、本地 diff、实验源文件 SHA256 |
| 构建与工具 | QEMU 路径/版本/configure，编译器、GDB、SystemC 版本 |
| 输入 | ELF、平台参数、UART 字节、寄存器配置 |
| 操作 | 完整命令、断点与控制动作 |
| 预期 | 状态、数据、事件次序与时间假设 |
| 实际 | 退出码、日志路径、寄存器/内存值 |
| 结论 | 通过、失败或未运行；失败时记录最早偏离点 |

状态必须按实验能力更新。例如 qtest 验证 DMA 后仍不勾选 Guest 驱动/CPU trap；Sv39 大页通过后仍不勾选三级小页遍历；SystemC 单端时间通过后仍不勾选跨端时间协调。
